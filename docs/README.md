## Термины (коротко)

- **Available** — доступный баланс (свободные средства в кошельке).
- **TVL** — заблокированный капитал в активных стратегиях.
- **Earned** — заработок: прибыль по стратегиям + реферальные выплаты.
- **Yield Multiplier** — бонус к общей прибыли за диверсификацию портфеля.
