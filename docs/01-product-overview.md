# Axon Capital — обзор продукта

## Что это

**Axon Capital** — крипто‑инвестиционная платформа, где пользователь:

- пополняет баланс (учёт в **USDT**),
- инвестирует в выбранные **стратегии** на заданный срок,
- получает **прибыль** по периодам,
- при завершении стратегии автоматически получает **возврат капитала**,
- может получать дополнительный бонус **Yield Multiplier** за диверсификацию,
- может зарабатывать на **14‑уровневой реферальной программе**,
- видит операции и статусы **в реальном времени**.

## Ключевые преимущества (понятно)

- **Прозрачная логика**: прибыль начисляется по периодам, все действия фиксируются в истории операций.
- **Автоматизация**: прибыль, бонус Yield Multiplier, возврат капитала и реферальные начисления рассчитываются системой.
- **Realtime UX**: баланс, статусы депозитов/выводов и операции обновляются без перезагрузки.
- **Гибкие сети**: пополнения/выводы поддерживают несколько сетей (USDT сети + Polygon).

## Базовая модель работы (в 4 шага)

1. **Регистрация / вход** → создание аккаунта.
2. **Пополнение** → создание заявки на депозит, оплата по реквизитам провайдера.
3. **Инвестирование** → выбор стратегии, суммы, срока → капитал блокируется в стратегии.
4. **Доход** → начисления прибыли по периодам + возврат капитала по окончании / при отмене.

## Что учитывается в продукте (что “зарабатывает”)

- **Пассивный заработок**: прибыль по активным стратегиям.
- **Бонус портфеля**: Yield Multiplier (бонус к общей прибыли за период).
- **Партнёрский доход**: проценты от прибыли пользователей вашей сети (до 14 уровней).
