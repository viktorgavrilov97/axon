# Безопасность, realtime и уведомления

## Безопасность аккаунта

Платформа использует стандартные меры безопасности:

- авторизация через сессии (NextAuth),
- хранение паролей в виде хэшей,
- валидация пользовательского ввода на сервере,
- ограничение частоты запросов (rate limiting) для защиты от спама.

## Роли и админ‑доступ

Есть роли:

- `USER` — обычный пользователь,
- `ADMIN` / `SUPERADMIN` — доступ к админ‑панели.

Админ‑панель используется для управления платформой (подтверждения/обработка статусов, управление конфигурациями стратегий и т.д.).

## Audit Log (журнал действий)

Критические действия (например, создание депозита/вывода, кредитование баланса, начисления прибыли) фиксируются в журнале.

Это помогает расследовать спорные случаи и проверять корректность изменений.

## Realtime‑обновления (без перезагрузки)

Интерфейс обновляется автоматически, когда:

- меняется баланс кошелька,
- меняется статус депозита,
- меняется статус вывода,
- создаётся операция (прибыль, бонус, возврат капитала, реферальная выплата).

Пользователь видит изменения “как в приложении”, без ручного refresh.

## Уведомления в Telegram (если подключено)

При подключении Telegram можно получать уведомления, например, о:

- подтверждении депозита,
- создании/статусах вывода,
- начислении прибыли по стратегии,
- начислении бонуса Yield Multiplier,
- реферальных начислениях.
